**Phase 1**

Policy Research Assistant

Goal:
Policy Agent-
This agent will allow users to query credit policy documents.

Capabilities:

- PDF ingestion
- Embeddings
- Semantic search
- RAG based responses
- Source retrieval and citation
------------------
  
**Phase 2**

Customer Risk Assessment 

Goal:
Build the Customer Risk Assessment capability and establish the Coordinator Agent as the single entry point for customer and policy requests.

Capabilities:

- Customer lookup
- Credit score evaluation
- Income analysis
- Credit utilization analysis
- Customer risk summarization
- Coordinator-based request routing
- Multi-agent request orchestration (Policy + Customer, without synthesis)

---------------
**Phase 3**

Intelligent Portfolio Intelligence & Semantic Orchestration

Goal:
Establish the intelligent orchestration foundation for CRISP by implementing semantic intent routing and reusable routing infrastructure, followed by delivering the Portfolio Intelligence capability for analytical portfolio assessment and business insights.

Capabilities

***Intelligent Semantic Orchestration***

- Semantic Intent Routing
- Embedding-based Intent Classification
- Reusable Intent Repository
- Routing Evaluation Framework
- Confidence-based Routing
- Routing Regression Testing
- Application Startup & Routing Bootstrap

***Portfolio Intelligence***

- Portfolio Data Foundation
- Portfolio Repository
- Portfolio Analytics
- Portfolio KPI Generation
- Segment Analysis
- Risk Distribution Analysis
- Exposure Analysis
- Default Rate Analysis
- Risk Trend Detection
- Concentration Analysis
- Portfolio Summary Generation
- Executive Portfolio Insights
- Coordinator Agent Integration

***Visual Intelligence***

- Portfolio Dashboard
- Interactive Portfolio Visualizations
- Analytical Charts & KPIs
- Executive Reporting
